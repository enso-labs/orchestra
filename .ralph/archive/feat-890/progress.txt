## Codebase Patterns
- BaseSandbox is in `deepagents.backends.sandbox`, response types in `deepagents.backends.protocol`
- Sync httpx.Client pattern (not async) — matches DaytonaSandbox convention
- Logger: `from src.utils.logger import logger` (loguru singleton)
- Sandbox factories registered in `_SANDBOX_FACTORIES` dict in `backend/src/agents/__init__.py`
- CompositeBackend wraps sandbox backends for dispatch
- `_resolve_user_settings()` returns 4-tuple — llm.py, stream.py, tasks.py must be committed atomically since stream_generator() signature changes
- Pre-commit hook stashes unstaged files — tightly coupled modules must be staged together or tests fail
- MCP error handling mirrors Daytona pattern: explicit mode raises/emits error, auto mode falls back to State
