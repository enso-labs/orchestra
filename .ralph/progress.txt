# Ralph Progress Log
Started: Wed Feb 11 2026

## Codebase Patterns
- Backend stack: Python 3.12+, uv, FastAPI, LangChain
- Conditional imports use try/except ImportError pattern (see src/tools/code.py)
- Backend init: CompositeBackend(default=StateBackend, routes=built_routes)
- Three entry points for backend: llm.py (invoke), stream.py (stream), tasks.py (worker)
- Config uses extra="allow" so metadata.sandbox is accessible without schema changes
- Tests in backend/tests/unit/ and backend/tests/integration/

- `langchain-daytona` depends on `daytona` package but doesn't pin a minimum version; without explicit `daytona>=0.140.0`, uv resolves to old v0.18.1 which uses `daytona_sdk` import name instead of `daytona`
- Run tests from backend/ dir: `make test`
- Commit with `-s` flag for sign-off per repo guidelines
