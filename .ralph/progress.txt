## Codebase Patterns
- Wiki is a git submodule - commit changes inside wiki/ first, then update submodule pointer in main repo
- Screenshots go in `wiki/static/img/<feature>/` and are referenced as `![alt](/img/<feature>/filename.png)` in docs
- Use agent-browser to capture screenshots: `agent-browser open <url>`, toggle to Day theme via UI, then `agent-browser screenshot <path>`
- The Day theme toggle is a dropdown accessed via the theme icon button, then selecting "Day" from the menu
- Scrollable container for assistant config is a div with class `h-full w-full rounded-[inherit]` - use `eval` to scroll it
- The "+" create button next to page headings can be targeted with CSS selector `h1 + button`
- Wiki builds with `npx docusaurus build` - pre-existing broken links don't block the build
- CodeMirror editor in memory create/edit form does NOT accept programmatic input via agent-browser fill/type or eval dispatch - screenshot the form as-is
- The Memories page is at `/memories` route (not in settings) - has its own sidebar link
- Memory detail view has Preview and Editor tabs - Preview shows rendered markdown, Editor shows raw with line numbers
- Schedules page at `/schedules` route - has Calendar, Table views with status cards (Total, Active, Upcoming, Overdue)
- Schedule creation starts with agent selection dialog, then a 3-step wizard (Details, When, What)
- The create "+" button on schedules can be clicked via `eval` with `button svg.lucide-plus` selector
- Missing docs pages can be sourced from `feat/810-docs-drift-wiki` branch using `git checkout remotes/origin/feat/810-docs-drift-wiki -- <path>`
- Projects section in sidebar is a collapsible button, not a direct page link - click to expand and see project list + Create Project button
