- Backend format check: `cd backend && make format` (runs `uvx ruff format`)

- Backend test: `cd backend && make test` (requires .env file)
- Git hooks: Worktree commits need `BEADS_DIR=/home/ryaneggz/ruska-ai/orchestra/.beads` env var set for pre-commit hook
- LLMService is in `backend/src/services/llm.py`, schemas in `backend/src/schemas/entities/llm.py`
- Assistant.files is Dict[str, str], LLMInput.files is Dict[str, Any]
- Assistant model has a model_validator preventing both system_prompt and instructions from being set at construction time, but direct attribute assignment bypasses this
- Running tests directly: `set -a && . $HOME/.env/orchestra/.env.backend && set +a && uv run pytest <path>` (tests/__init__.py imports app, needs full env)
- Git operations in worktree: run from worktree root, not from `backend/` subdir
- Async integration tests: use `unittest.IsolatedAsyncioTestCase` + `AsyncMock` for service method mocking
- Mock `LLMService.init_tools` with `@patch.object` to avoid A2A/MCP/tool loading in tests
- Wiki is a git submodule: commit inside `wiki/` first (on a branch), then `git add wiki` in the parent repo
- Wiki sidebar: `wiki/sidebars.ts` — Core Features items array and Tutorials items array
- Wiki doc frontmatter pattern: `title`, `slug`, `sidebar_position` (see `wiki/docs/assistants/index.md`)
