## Codebase Patterns
- Backend middleware lives in `backend/src/utils/middleware.py` using `@wrap_model_call` decorator pattern and `AgentMiddleware` class pattern
- Constants go in `backend/src/constants/llm.py` - use `DEFAULT_CHAT_MODEL_BASIC` for low-cost model
- Format/lint with `uvx ruff format` and `uvx ruff check` from worktree root
- Commits must be signed (`git commit -s`)
- Phase 2B chosen: full Orchestra implementation (deepagents has no built-in compaction)
- `init_default_middleware()` returns the middleware list; new middleware should be added there
- `AutoEvictMiddleware` is a class-based middleware extending `AgentMiddleware` from deepagents
- `@wrap_model_call` middlewares receive `(request: ModelRequest, handler)` and return `ModelResponse`
- SystemMessage accepts `metadata` dict in constructor for tagging messages
- Use `ainvoke` for async LLM calls with init_chat_model instances
- `@wrap_model_call` decorated functions are NOT `callable()` - they produce middleware objects, not plain functions
