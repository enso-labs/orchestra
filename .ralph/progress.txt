## Codebase Patterns
- Website is a git submodule — must commit inside `website/` directory, not from orchestra root
- Website uses Next.js with TypeScript, framer-motion for animations, Tailwind CSS for styling
- Services page uses `font-montserrat` for body text, `font-space` for hero branding
- CTA links point to `https://cal.com/ruska-ai/ai-audit`
- Run typecheck with `npx tsc --noEmit` from `website/` directory
- Custom CSS animations go in `website/src/app/globals.css` (e.g., marquee, fadeIn)
- Next.js OG images: use `opengraph-image.tsx` with `ImageResponse` from `next/og`, export `size` and `contentType`
- Next.js robots/sitemap: use `robots.ts` / `sitemap.ts` with `MetadataRoute` types
- JSON-LD in client components: `<script type="application/ld+json" dangerouslySetInnerHTML={{ __html: JSON.stringify(...) }} />`
- Blog posts live in `website/posts/` as markdown files, use `getAllPostSlugs()` from `@/lib/posts`
- llm.txt is generated via `website/scripts/generate-llm-txt.mjs`, regenerated by `npm run prebuild`
