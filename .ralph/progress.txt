## Codebase Patterns
- Backend tests require env vars loaded from `$HOME/.env/orchestra/.env.backend` (no `.env.test` in worktrees)
- Run tests with: `set -a && source /home/ryaneggz/.env/orchestra/.env.backend && set +a && uv run pytest tests/unit -s`
- Format with: `uvx ruff format` from backend dir
- Lint check with: `uvx ruff check <files>`
- `init_default_middleware()` in `src/utils/middleware.py` reads `USE_INTERNAL_SUMMARIZATION` env var to toggle compaction middleware
- Commits must be signed: `git commit -s`
- `Assistant` and `LLMRequest` schemas live in `backend/src/schemas/entities/llm.py`; new fields need wiring in `to_llm_request()`
- `init_graph()`, `Orchestra.__init__()`, and `construct_agent()` all live in `backend/src/agents/__init__.py`
- `construct_agent()` uses `agent_name` param which maps to `name` on `Orchestra` and `init_graph` (and ultimately `create_deep_agent`)
- Full param wiring chain: LLMRequest -> LLMController -> stream_generator() -> construct_agent() -> Orchestra -> init_graph() -> create_deep_agent()
- Pre-existing lint errors in `stream.py` (`current_agent` undefined in `handle_multi_mode`) — do not fix as part of unrelated stories
- `init_chat_model` is a local import inside `init_graph()` — mock it at `langchain.chat_models.init_chat_model`, not at the `src.agents` level
- `create_deep_agent(backend=StateBackend)` is the public API for backends — pass the class as a callable, framework constructs ToolRuntime internally
- `USE_AGENTS_MD_INSTRUCTIONS` env var (default: `true`) controls system_prompt → AGENTS.md migration in `init_graph()`; when true, system_prompt is written to a temp AGENTS.md file and loaded via `memory` param
- API paths use `/api/llm/invoke`, `/api/llm/stream` — NO version prefix (not `/api/v0/...`)
- Distributed streaming: POST `/api/llm/stream` returns 202 with `thread_id`, GET `/api/threads/{id}/stream` provides SSE events
- Pre-existing 404 errors on "recent executions" endpoint — not related to schema changes
