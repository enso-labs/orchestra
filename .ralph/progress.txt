## Codebase Patterns
- Backend unit tests use `unittest.IsolatedAsyncioTestCase` with `asyncSetUp()` for async tests
- Use `AsyncMock` for mocked async services, `MagicMock` for sync services with async methods set via `service.method = AsyncMock(...)`
- `Assistant.files` is `Dict[str, str]` — AGENTS.md key is just `"AGENTS.md"` (not `/AGENTS.md`)
- Assistant model validates that only ONE of `system_prompt` or `instructions` can be set (model_validator)
- When setting `instructions` from AGENTS.md, must set `system_prompt = None` first to pass validation
- `LLMInput.files` is `Dict[str, Any]` — values can be string, dict with 'content' key, or list
- Tests require env vars loaded: `set -a && . ~/.env/orchestra/.env.backend && set +a`
- Run tests: `uv run pytest tests/unit/services/test_llm_agents_md.py -v`
- Format/lint: `uvx ruff format <file> && uvx ruff check <file> --fix`
