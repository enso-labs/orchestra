## Codebase Patterns
- Base class for SQLAlchemy models: `from src.services.db import get_db_base; Base = get_db_base()`
- UUID primary keys: `UUID(as_uuid=True)` with `server_default=sa.text("uuid_generate_v4()")`
- Timestamps: `DateTime(timezone=True)` with `server_default=func.now()` and `onupdate=func.now()`
- Enums: inherit from `str, enum.Enum` for Pydantic compatibility
- Encryption: use `src.utils.security.encrypt_value()` / `decrypt_value()` for Fernet encryption
- Models exported from `src.schemas.models.__init__`
- Pydantic schemas go in `src.schemas.entities/`
- Migrations in `backend/migrations/versions/` with sequential numbering (0000, 0001, 0002...)
- Foreign keys: `sa.ForeignKey("table.id", ondelete="CASCADE")`
- Pyright has baseline import errors (can't resolve packages in this env) - these are pre-existing
- Format: `make format` runs `uvx ruff format` from backend/
- Commit with `-s` flag for sign-off
- SSRF validation: use `_is_private_url()` from `src.schemas.entities.server` for URL validation
- Schema pattern: Create (required), Update (all Optional), Response (with id/timestamps + redaction)
