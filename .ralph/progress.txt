## Codebase Patterns
- `make format` (ruff) must be run from `backend/` directory, not project root
- Schema entities are exported through `backend/src/schemas/entities/__init__.py` - add new types there
- Settings patterns: UserSettings (entity), UserSettingsResponse (API response), Update*Request (request body)
- Existing settings use Optional[str] for nullable fields (not the enum type directly)
- Ruff format may reformat test files with long lines - include those in commits
- test_worker_model_resolution.py has 5 pre-existing failures (src.agents.init_backend missing) — ignore these
- Repo tests use @patch decorators on the class; each test method gets injected positional args (_dec, _enc)
- resolve_sandbox_backend(runtime, sandbox_type=None) dispatches via _SANDBOX_FACTORIES; callers pass sandbox_type from user settings
