## Codebase Patterns
- Agent construction: `backend/src/agents/__init__.py` — `construct_agent()` + `resolve_sandbox_backend()`
- Sandbox factory dict: `_SANDBOX_FACTORIES` maps type strings to factory functions
- `resolve_sandbox_backend()` dispatches based on sandbox_type param
- `FilesystemBackend` (lowercase 's') available from `deepagents.backends` — NOT `FileSystemBackend`
- `CompositeBackend` wraps the actual backend — all factories return `(CompositeBackend, sandbox_or_None)`
- `DISTRIBUTED_WORKERS` env var at `backend/src/constants/__init__.py:131` — already defaults to `false`
- TaskIQ imports in `backend/src/routes/v0/llm.py:22` and `backend/src/workers/`
- Backend Makefile: `dev` (port 8000), `dev.claude` (port 8031), `dev.worker` (TaskIQ)
- Build script: `backend/scripts/build.sh` — Docker build with ghcr.io registry
- Reference install patterns: `ruska-ai/sandboxes` openclaw branch
