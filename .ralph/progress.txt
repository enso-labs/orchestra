## Codebase Patterns
- Backend format: `cd backend && make format` (runs `uvx ruff format`)
- Backend lint: `uvx ruff check <file>` for quick lint checks
- Backend tests: `cd backend && set -a && . $HOME/.env/orchestra/.env.backend && set +a && uv run pytest` (env required)
- Unit tests can be run individually: `uv run pytest tests/unit/repos/test_skill_repo.py -v`
- Schema entities follow pattern in `backend/src/schemas/entities/memory.py` — BaseModel with Create/Update/ListResponse variants
- Commits must be signed: `git commit -s`
- Frontend hooks: state + handlers in `hooks/use<Entity>.ts`, context wrapper in `context/<Entity>Context.tsx` (see AgentContext pattern)
- Frontend typecheck: `cd frontend && npx tsc --noEmit`
- Wiki is a git submodule — commit changes in `/wiki/` directory directly, not through main repo
- Wiki build: `cd wiki && npm install && npm run build` (Docusaurus)
- Browser testing: Monaco editor content must be set via `eval` with `window.monaco.editor.getEditors()[0].setValue()` — agent-browser `type` hangs on Monaco
- Browser testing: Use CSS selectors for icon-only buttons when accessibility refs are unreliable (e.g., `.text-destructive` for trash icon)
