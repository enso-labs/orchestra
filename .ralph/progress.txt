## Codebase Patterns
- Tools follow `@tool + RunnableConfig` pattern (see `backend/src/tools/memory.py`)
- Extract user_id from `config["configurable"].get("user_id")`
- `ScheduleService.create_job()` type hint says `Job` but actually accepts `ScheduleCreate` (has title, trigger, task fields)
- Line length limit is 120 chars (ruff E501)
- 2 pre-existing integration test failures in `tests/integration/test_default_system_prompt_runtime.py` (LangSmith) - unrelated to feature work
- To register new tool sets: import in `backend/src/tools/__init__.py`, spread into `default_tools()` list
- To test `@tool` functions: use `@patch("src.tools.<module>.<singleton>")` and call via `tool.ainvoke(args_dict, config=RunnableConfig(configurable={...}))`
- Repos extend `BaseRepo(user_id, store, entity_type)` — use `_get(key)`, `_set(key, model)`, `_delete(key)` for CRUD
- Single-entity repos (like settings/config) use a fixed key constant (e.g., `_KEY = "config"`)
- `_get()` returns an item with `.value` dict — call `Model.model_validate(item.value)` to deserialize
- BaseRepo._format() only handles a fixed set of entity types — new repos should bypass it and validate directly
- Services accept `Optional[BaseStore] = None` and default to `get_store_in_memory()` in `__init__`
- `Config` (LLMRequest metadata) has `extra="allow"` — pass extra fields like `source` as a dict to bypass Pyright
- `DEFAULT_CHAT_MODEL_BASIC` from `src.constants.llm` is the cheapest available model
- `scheduled_llm_invoke()` returns response dict in-process, `None` in distributed mode
- Thread creation for escalation: `ThreadService.create(Thread(id=..., title=..., messages=[...], metadata={...}))`
- TaskIQ scheduling: `ScheduledTask(task_name=..., interval=seconds, kwargs={...})` + `ListRedisScheduleSource.add_schedule()`
- `ListRedisScheduleSource(url=REDIS_URL)` is lightweight — instantiate per-call
- `ScheduledTask.schedule_id` is auto-generated — read after construction
- Lazy imports inside methods must be patched at source module (e.g., `taskiq.ScheduledTask` not `src.services.heartbeat.ScheduledTask`)
