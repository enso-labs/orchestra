- Added Video-to-GIF Conversion section to SKILL.md with complete ffmpeg pipeline
- Two-pass palettegen/paletteuse filter chain for optimal GIF color quality
- Lanczos scaling for high-quality downscaling, infinite loop (-loop 0) by default
- Default 12 FPS and 800px max width, with user override support (clamped to valid ranges)
- Post-conversion: verify GIF, delete intermediate .webm, report result
- Files changed: `.claude/skills/video-gif-generation/SKILL.md`
- **Learnings for future iterations:**
  - ffmpeg's `filter_complex` with palettegen+paletteuse produces significantly better GIF quality than single-pass `-vf` conversion
  - Sierra 2-4a dithering (`sierra2_4a`) is a good balance of quality and file size for screen recordings
  - Always clamp user-provided values to valid ranges rather than rejecting them outright

- **Learnings for future iterations:**
