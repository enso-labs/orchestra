## Codebase Patterns
- Backend format/lint: `cd backend && make format` runs `uvx ruff format`
- `create_file_data(content: str)` from `deepagents.backends.utils` returns `{content: list[str], created_at: str, modified_at: str}`
- `MemoryService.search()` returns `list[SearchItem]` where each item has `.dict()` → `{key, value, ...}` and `value` is typically `{"memory": "text"}`
- Use `TYPE_CHECKING` guard for `MemoryService` import in agents/__init__.py to avoid circular imports
- Pre-existing ruff lint warning (F401) on unused `create_agent` import in agents/__init__.py — not our change
- Memory wiring pattern: call `prepare_memory_files()` → merge `{**memory_files, **files_map}` → pass `memory_sources` to `construct_agent(memory=...)`
- Unit test convention: use `@pytest.mark.asyncio` on classes, `pytest-asyncio` auto mode, `unittest.mock.AsyncMock` for async methods, `patch("src.module.name")` for patching
