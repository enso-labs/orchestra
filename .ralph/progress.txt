## Codebase Patterns
- Backend tests require env loaded: `set -a && . $HOME/.env/orchestra/.env.backend && set +a`
- Run backend tests from `backend/` directory: `uv run pytest`
- No mypy/pyright installed; use `py_compile` for basic typecheck
- `LLMInput.files` is `Optional[Dict[str, Any]]` — values can be str, dict, list
- `LLMRequest.instructions` defaults to `""` (empty string)
- `LLMService.assistant()` has two paths: agent mode (with assistant_id) and non-agent/thread mode
- Agent mode AGENTS.md extraction: lines 155-158 of `backend/src/services/llm.py`
- Non-agent path AGENTS.md extraction: lines 174-185 of `backend/src/services/llm.py`
- `_make_params()` helper in tests constructs LLMInput with files parameter directly, not via kwargs override
- Frontend tests: `cd frontend && npx vitest run` — uses jsdom, globals: true, @testing-library/react
- Mock contexts by mocking the hook module before importing component: `vi.mock("@/context/AgentContext", ...)`
- Mock react-router-dom with `vi.mock("react-router-dom", ...)` for `useNavigate`/`useParams`
- Agent form no longer uses Tabs — Instructions/System Prompt tabs were removed in US-006
- `AgentCreateForm` imports from: AgentContext, ChatContext (toBackendFormat), react-router-dom, SelectModel, ToolSelectionModal (MonacoEditor and PromptSelectionModal removed in US-006)
- When using `getByText(/AGENTS\.md/)` in tests, ensure "AGENTS.md" text appears in only ONE text node (not in both a title and a `<strong>` tag)
- TypeScript check: `npx tsc --noEmit --pretty` (no errors expected)
- Radix UI Switch (used in Public toggle) requires `ResizeObserver` polyfill in jsdom — add `global.ResizeObserver` stub in test files that render agents with `agent.id` set
- Agent type from `agentService.ts` has `instructions?: string`, `system_prompt?: string`, `files?: Record<string, string>` — use these for legacy migration card tests
- `createFile(path, content)` from `useChatContext()` creates files in the agent's file system (delegates to `useFileSystem` hook)
- Use `isMigrated` local state as guard when `createFile` doesn't instantly update `agent.files` in context
- Intro.js: use `introJs.tour()` factory, `tour.setOptions({ steps: [...] })`, `tour.start()`, `tour.exit(true)` for cleanup
- `useIntroTour` hook: `useIntroTour(tourId, steps, options?)` → `{ startTour, isComplete, resetTour }`, localStorage key: `orchestra:tour:{tourId}:dismissed`
- When `useIntroTour` has `autoStart: true`, mock it in tests: `vi.mock("@/hooks/useIntroTour", ...)` — prevents Intro.js DOM overlays from breaking `getByText` queries
- Tour step selectors: use `data-tour="x"` attributes for same-component elements; `[aria-label="x"]` for cross-component elements (ChatNav, FileTreeHeader, FileEditorPanel)
