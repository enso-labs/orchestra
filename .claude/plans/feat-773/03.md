# Plan: Iteration 3 — Auto-Sync Fix & AI-Powered Skill Generation

## Context

PR comment [#774 (comment)](https://github.com/ruska-ai/orchestra/pull/774#issuecomment-3903208976) identifies two issues:

1. **Bug**: Agent-generated skills don't appear on `/skills` page after chat session ends
2. **Feature request**: "Generate with AI" — use the [skill-builder-agent](https://raw.githubusercontent.com/ryaneggz/ralph/refs/heads/master/.claude/agents/skill-builder.md) pattern to generate best-practice SKILL.md templates from the create page

The goal is to update `tasks/prd-skills-crud.md` (add Iteration 3 section) and `.ralph/prd.json` (add US-026 through US-033).

## Root Cause Analysis: Auto-Sync Bug

**Location**: `backend/src/utils/stream.py` line 336

**Problem**: `stream_generator()` passes the streaming-accumulated `files_map` to `sync_skill_files_to_store()`. This `files_map` is built incrementally from chunks (line 284: `files_map = {**files_map, **chunk_data["files"]}`), which may be incomplete — if the agent writes a skill file in its last tool call, the final state may not have been emitted as a "values" chunk before the stream ends.

**Contrast**: `llm_invoke()` (in `backend/src/controllers/llm.py` line 179) correctly uses `final_state = await agent.graph.aget_state(config)` then `final_state.values.get("files", {})` — the authoritative final agent state.

**Fix**: Use `final_state.values.get("files", {})` in `stream_generator()` too — `final_state` is already fetched at line 307. Fall back to accumulated `files_map` if `final_state` is unavailable.
