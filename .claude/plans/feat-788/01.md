# Rename Schedules → Crons

## Context

Pure naming convention change across the full stack. `schedule/schedules` → `cron/crons` everywhere: files, classes, functions, variables, routes, API endpoints, DB table, React Query keys, sidebar labels.

## Approach

Systematic find-and-replace in dependency order: schema → backend services → routes → frontend entities → services → hooks → components → pages → routes.

## Step 1: Backend Schema

**File**: `backend/src/schemas/entities/schedule.py` → rename to `cron.py`
- Rename all classes: `Schedule*` → `Cron*`
- Update `__init__.py` imports in `backend/src/schemas/entities/`

## Step 2: Backend Service

**File**: `backend/src/services/schedule.py` → rename to `cron.py`
- `schedule_service` → `cron_service`
- All method names: `*_schedule*` → `*_cron*`
- Update `backend/src/contexts/service.py` — `schedule_service` field → `cron_service`

## Step 3: Backend Routes

**File**: `backend/src/routes/v0/schedule.py` → rename to `cron.py`
- All endpoint paths: `/schedules` → `/crons`, `/schedule` → `/cron`
- Update `backend/src/routes/v0/__init__.py` — import + router registration

## Step 4: Backend References

- `backend/src/workers/tasks.py` — update schedule references
- `backend/src/controllers/llm.py` — update schedule references
- `backend/src/constants/examples/__init__.py` — update any schedule examples
- `backend/src/services/checkpoint_resilient.py` — update references

## Step 5: Database Migration

- Create migration to rename table `schedules` → `crons`
- Update any column references if needed

## Step 6: Frontend Entities & Services

- `frontend/src/lib/entities/schedule.ts` → `cron.ts` — rename types
- `frontend/src/lib/services/scheduleService.ts` → `cronService.ts` — rename + update API paths
- `frontend/src/lib/utils/schedule.ts` → `cron.ts` — rename utils

## Step 7: Frontend Hooks

- `frontend/src/hooks/useSchedules.ts` → `useCrons.ts`
- `frontend/src/hooks/useAgentSchedules.ts` → `useAgentCrons.ts`
- `frontend/src/hooks/useScheduleExecutions.ts` → `useCronExecutions.ts`
- Update React Query keys

## Step 8: Frontend Components

- `ScheduleCalendar.tsx` → `CronCalendar.tsx`

## Step 9: Frontend Pages & Routes

- `frontend/src/pages/schedules/` → `frontend/src/pages/crons/`
- `frontend/src/routes/AppRoutes.tsx` — `/schedules` → `/crons`
