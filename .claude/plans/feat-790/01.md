# Better Tool Configuration UI for Super Agent Chat Session

## Context

The chat page currently uses `BaseToolMenu` — a simple dropdown with web search toggle, PII toggles, and image upload. The Assistant Create/Edit pages have a full `ToolSelectionModal` with platform tools, custom API tools, MCP servers, and A2A agents. Users want that same rich tool config accessible from the chat page.

## Strategy

**Minimal changes, maximum reuse.** The `ToolSelectionModal` already works with `AgentContext` and already updates the agent's tools/MCP/A2A config. We just need to:

1. Add a "Configure Tools" entry to `BaseToolMenu` that opens the modal
2. Wire the modal's `onApply` to update `AgentContext` tools
3. Show a visual indicator of how many tools are active

The modal already handles all the complex UI (platform tools grid, MCP server management, A2A agent discovery, custom API tool creation). No need to rebuild any of that.

## Step 1: Add ToolSelectionModal to BaseToolMenu

**File**: `frontend/src/components/menus/BaseToolMenu.tsx`

- Import `ToolSelectionModal`
- Add state: `const [showToolModal, setShowToolModal] = useState(false)`
- Add a "Configure Tools" `DropdownMenuItem` with a Wrench icon that opens the modal
- Render `<ToolSelectionModal>` with:
  - `isOpen={showToolModal}`
  - `onClose={() => setShowToolModal(false)}`
  - `initialSelectedTools={agent.tools}`
  - `initialMcpConfig={agent.mcp || {}}`
  - `initialA2aConfig={agent.a2a || {}}`
  - `onApply={(tools) => setAgent({...agent, tools})}`

## Step 2: Add Active Tools Indicator

**File**: `frontend/src/components/menus/BaseToolMenu.tsx`

- Show a badge count on the `+` button when tools are configured beyond defaults
- Or show selected tool count in the dropdown header

## Step 3: Ensure Chat Submission Includes Tools

**File**: `frontend/src/hooks/useChat.ts`

- Verify that `agent.tools`, `agent.mcp`, and `agent.a2a` are included in the stream payload
- This should already work since `AgentContext` is the source of truth and `handleSSEUnified` reads from it

## Step 4: Improve BaseToolMenu Layout

**File**: `frontend/src/components/menus/BaseToolMenu.tsx`

- Group existing toggles (web search, PII) more cleanly
- Add a section header "Quick Toggles" for the inline toggles
- Add a section header "Advanced" for the "Configure Tools" button
- Keep image upload at the top

## Step 5: Tests & Browser Validation

- Verify modal opens from chat page
- Verify tool selection persists in session
- Verify selected tools are sent with next chat message
- Screenshot with agent-browser

## Risks

- **Modal size on mobile**: ToolSelectionModal is 1400px wide — may need responsive adjustments for chat page context. It already has `sm:w-[95vw]` so should be fine.
- **Default tools**: BaseToolMenu currently force-adds `DEFAULT_AGENT_TOOLS` on mount. Need to ensure this doesn't conflict with modal selections.
