## How to Use This Index

### Adding New Announcements
When the pr-announcer agent generates a new announcement, it will:
1. Create a file in the appropriate `YYYY-MM/` folder
2. Add an entry to the table above
3. Update the Quick Stats section

### Providing Feedback
After posting announcements to social media:
1. Create a feedback file at `_feedback/PR-{number}-feedback.md`
2. Record engagement metrics (impressions, likes, comments, shares)
3. Note what worked and what could improve
4. The agent will use this feedback in future cycles

### Feedback File Template
```markdown
# Feedback: PR #[number]

## Engagement Results
| Platform | Impressions | Likes | Comments | Shares |
|----------|-------------|-------|----------|--------|
| LinkedIn | [count] | [count] | [count] | [count] |
| X.com | [count] | [count] | [count] | [count] |

## What Worked
- [Element that performed well]

## What Didn't Work
- [Element that underperformed]

## Recommendations for Future
- [Specific recommendation]
```
