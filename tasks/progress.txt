## Codebase Patterns
- Search providers return `(results, error)` tuple pattern
- Tavily uses inline import inside the helper function
- Constants are in `backend/src/constants/__init__.py` with `UserTokenKey` enum + module-level `os.getenv()`
- Search tools are in `backend/src/tools/search.py`
- Frontend search component at `frontend/src/components/tools/SearchEngine.tsx`
