## Codebase Patterns
- `scheduled_llm_invoke()` must be a module-level function (not a method) for APScheduler pickling
- Imports inside `scheduled_llm_invoke()` function body are intentional for pickling support
- `DISTRIBUTED_WORKERS` is now in `src/constants/__init__.py` (consolidated)
- Use `make format` (runs `uvx ruff format`) for formatting, `make test` for running tests
- Tests need env vars: `set -a && . ~/.env/orchestra/.env.backend && set +a` before pytest
- Patch `src.constants.DISTRIBUTED_WORKERS` to control dispatch path in tests
