## Codebase Patterns
- DISTRIBUTED_WORKERS is imported inside function body (not module-level) in schedule.py for APScheduler pickle compatibility
- Patch `src.constants.DISTRIBUTED_WORKERS` (not `src.services.schedule.DISTRIBUTED_WORKERS`) when testing functions that import it inside their body
- Backend tests require env vars loaded from `~/.env/orchestra/.env.backend` — use `set -a && . ~/.env/orchestra/.env.backend && set +a` before pytest
- Use `make format` in backend/ to run ruff formatting
